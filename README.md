# R3F workshop demos

Standalone demos from the Advanced React Three Fiber workshop.

## Get started

You'll need Node.js, pnpm, and a browser with WebGPU support.

```sh
pnpm install
pnpm dev
```

Open a demo at `http://localhost:5173/<route>`, for example

## Available demos

| Route | Description |
| --- | --- |
| `/ball-collision` | Starter scene with a red circle bouncing between two bounds. |
| `/ball-collision-zustand` | Drag, fling, and collide balls using Zustand. |
| `/ball-collision-koota` | Ball collisions using Koota. |
| `/ball-collision-steps` | Five lessons from rendering to Koota. [Lesson guide](src/demos/ball-collision-steps/README.md). |
| `/paris-hero` | A Paris scene with the Eiffel Tower, sky, and postprocessing. |
| `/magic-box` | A portal cube showing the number ten in six writing systems. |
| `/grain-gradient` | Drifting gradient blobs with a grain effect. |
| `/flip-grid` | Tiles that flip under the cursor. |
| `/connectors` | A spring-driven Rapier physics pile. |
| `/blending-cube` | A cube with edges, shadows, metalness, and an environment. |
| `/takehome-grid` | Six flipping tiles introducing the other demos. |
| `/block-city` | Hundreds of animated, instanced blocks. |
| `/postprocessing` | Bloom and ambient occlusion with adjustable controls. |
