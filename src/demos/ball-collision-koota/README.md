# Ball collision with Koota

The same balls, drag and fling, walls, collisions and Devtools as [the Zustand demo](../ball-collision-zustand/).

Matches lesson 6: Koota holds the data, and each ball syncs its mesh position through a ref after physics, avoiding movement rerenders.

[Start with Koota in lesson 5](../ball-collision-steps/05-koota/README.md), then [switch to mesh refs in lesson 6](../ball-collision-steps/06-refs/README.md).
